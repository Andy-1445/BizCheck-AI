# BizCheck AI

BizCheck AI is a company information and analysis application with a FastAPI backend and React frontend.

See [backend/README.md](backend/README.md) and [frontend/README.md](frontend/README.md) for setup and development instructions.

The repository includes source code and benchmark catalog metadata. Local API credentials, databases, imported datasets, generated media, test artifacts, and private documents are intentionally excluded. Copy each `.env.example` to a local `.env` and fill in values only on your own machine or deployment platform. Keep credentials out of Git.
